## 中文与中英混排

学习有时从一个很小的问题开始：读到一个不明白的概念，尝试一种新的方法，或在实践中遇到一个意外的结果。把问题写下来，把过程整理清楚，再回头看时，往往会多一点理解。

此在用于记录学习、思考与实践成果。希望每一次记录，都能留下值得重读的内容。

Writing helps turn scattered notes into clearer ideas. Learn, build, reflect, and keep a record of the process.

中英混排也很常见：用 Python 整理数据，用 Git 管理版本，再用 Markdown 写下观察与结论。数字与符号示例：2026、3.14、100%、（圆括号）、“中文引号”、——破折号。

## 标题与文字强调

### 用小标题组织内容

二级标题适合划分主要部分，三级标题适合补充细节。页面会根据标题自动生成文章目录，点击目录可以跳到对应位置。

这是一段普通文字，也可以标出 **需要记住的结论**、_想要强调的语气_，或者用 ~~删除线~~ 标记已经修正的说法。命令、变量和文件名可以写成行内代码，例如 `git status`、`learning_notes` 和 `example.md`。

## 列表与引用

写一篇学习笔记时，可以先列出几个问题：

- 我想弄明白什么？
- 我尝试了哪些方法？
- 有什么证据支持当前的结论？

再按顺序整理过程：

1. 描述问题和已有背景。
2. 记录尝试、观察和必要的数据。
3. 总结收获，并留下还没有解决的问题。

> 把一个问题弄明白，再用自己的话写下来。记录不必一次写完，也可以随着理解加深不断修订。

## 代码示例

下面用一个简单的 Python 函数计算平均值。代码块会显示语法高亮，并提供复制按钮。

```python
def average(values: list[float]) -> float:
    if not values:
        raise ValueError("列表不能为空")
    return sum(values) / len(values)


scores = [80, 85, 90]
print(f"平均值：{average(scores):.1f}")
```

这段代码的输出是 `平均值：85.0`。记录代码时，可以同时解释输入、输出和使用条件，方便日后重读。

## 用表格整理记录

| 记录类型 | 可以写什么             | 值得保留的内容     |
| -------- | ---------------------- | ------------------ |
| 学习笔记 | 概念、问题与自己的理解 | 参考资料和解释     |
| 实践过程 | 方法、步骤与观察       | 环境、参数和结果   |
| 成果整理 | 做成了什么、解决了什么 | 复现方式与后续改进 |

## 从这篇示例开始写作

这篇文章的源文件是 `src/content/posts/example.md`。复制它并换一个文件名，修改文件开头的标题、简介、发布时间和标签，就可以开始写下一篇文章。

还在整理时，可以把 `draft` 设为 `true`；准备公开时改回 `false`。如果希望文章出现在首页的精选区域，可以保留 `featured: true`。
